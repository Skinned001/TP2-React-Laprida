# TP2-React-Laprida

App **Comedor IPF** para el TP2 de React Native, armada con Expo Router, TypeScript y Expo SDK 57.

## Arrancar la app

```bash
npm ci
npm run start
```

## Rutas iniciales

```text
src/
└── app/
    ├── _layout.tsx   # Stack raíz
    └── index.tsx     # Inicio (/)
```

La estructura de rutas y los navegadores se va a ampliar a medida que avancemos con el TP.
